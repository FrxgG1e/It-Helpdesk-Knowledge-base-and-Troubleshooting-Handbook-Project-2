IT Helpdesk Knowledge Base & Troubleshooting Playbook

Author: Ngcaphephe Ngqakayi | Role Focus: Tier-1 Systems & Technical Support

A structured Tier-1 IT Support and Cybersecurity Operations manual documenting standard diagnostic workflows, Windows Cli troubleshooting, and escalation protocols.

SOP-001 | Networking

No Internet Access / DNS Resolution Failure

Symptoms: User is connected to Wi-Fi or Ethernet, but websites fail to load with "DNS_PROBE_FINISHED_NXDOMAIN" or timeout errors.

Troubleshooting Steps:

  • Verify physical cable or Wi-Fi connection status and check if airplane mode is off.
  • Open Command Prompt and run ipconfig /all to verify a valid IPv4 address (not an APIPA 169.254.x.x address).
  • Test local gateway reachability using ping 192.168.1.1 (or default gateway IP).
  • Test external IP connectivity using ping 8.8.8.8. If IP ping succeeds but domain names fail, clear DNS cache with ipconfig /flushdns.
  • Renew DHCP lease via ipconfig /release followed by ipconfig /renew.

Escalation Criteria: Escalate to Tier-2 Network Admin if multiple users on the same switch/VLAN lose connectivity simultaneously.

SOP-002 | Cybersecurity Triage

Suspicious Phishing Email Reported by End User

Symptoms: Employee reports an unexpected email requesting urgent password resets, invoice payments, or containing unfamiliar attachments.

Troubleshooting & Containment Steps:

  • Instruct the user not to click links, download attachments, or reply to the sender.
  • Inspect the sender address carefully for lookalike domains (typosquatting) and hover over links to check actual destination URLs.
  • Review email headers (SPF, DKIM, and DMARC status) to verify sender authenticity.
  • If the user already clicked a link or entered credentials, immediately reset their account password, revoke active sessions, and run a full antivirus/EDR scan on their workstation.

Escalation Criteria: Escalate immediately to the Security Operations team with the original .eml file attached so the sender domain can be blocked organization-wide.

SOP-003 | Identity & Access

User Account Lockout & Forgotten Password

Symptoms: User cannot log into Windows workstation or Microsoft 365 portal due to repeated failed password attempts.

Troubleshooting Steps:

  • Verify user identity following company verification policy (employee ID, manager confirmation, or security challenge).
  • Check Active Directory / Entra ID for account lockout status and inspect recent sign-in logs for unusual IP locations.
  • Unlock the account and issue a temporary password with "User must change password at next logon" enabled.
  • Check if cached credentials on a mobile device or mapped network drive are repeatedly triggering lockouts.

Escalation Criteria: Escalate to Security if sign-in logs show brute-force login attempts from unfamiliar foreign IP addresses.

SOP-004 | OS Performance

Slow Workstation Performance / High CPU or RAM Usage

Symptoms: Windows workstation freezes, applications lag, or fan noise runs continuously.

Troubleshooting Steps:

  • Open Task Manager (Ctrl + Shift + Esc) and inspect CPU, Memory, and Disk utilization under the Processes tab.
  • Identify runaway background tasks or memory-heavy browser tabs and end unresponsive processes safely.
  • Check Startup apps tab and disable non-essential programs launching at boot.
  • Run sfc /scannow in an elevated Command Prompt if Windows system file corruption is suspected, then perform a clean reboot.

Escalation Criteria: Escalate to Hardware Support if SMART diagnostics indicate failing storage drives or insufficient physical RAM for required role software.

SOP-005 | Peripherals

Network Printer Offline or Stuck Print Queue

Symptoms: Print jobs remain stuck in queue or printer displays "Offline" status on user's PC.

Troubleshooting Steps:

  • Confirm the printer is powered on, has paper/toner, and displays no hardware error codes on its LCD screen.
  • Ping the printer's static IP address from Command Prompt (ping [Printer_IP]) to verify network reachability.
  • Open services.msc, locate the Print Spooler service, and click Restart to clear stuck print jobs.
  • Send a test page to confirm resolution.

Escalation Criteria: Escalate to Vendor Support if hardware jams persist or internal rollers/fusers require physical replacement.

SOP-006 | Escalation

Premature Escalation (Hot-Potatoing)

Symptoms:Tickets arrive in Tier 2 with one-line summaries like "User caannot connect" or "App crashing, please fix.", showing no record of what was checked. Other symptoms include: Skipped Basic Diagnostics, Ultra-Fast Transfer Times and Missing User Environment Details.

Troubleshooting Steps:

  • Pull recent escalated tickets and review them side-by-side with the agent. Inquire on "where they got stuck?"
  • Require the agent to fill out a short form in the internal notes before transferring a ticket. Include fields for User's Device/OS, Error Message, KB Article Checked, and 3 Troubleshooting Steps Attempted.
  • Reguire the agent to message a Team Lead or senior peer in SLacks/Teams for a quick thumbs-up or approval check.
  • Give Tier 2 Bounce Back authority for that specific agent's escalations.

Trigger Criteria:High Bounce-Back rates, Template Bypass, Unapproved Transfers.

Escalation Criteria:Remove thier permission to escalte tickets directly in your ticketing software. Route all their transfers to a "lead Review" queue first, or resrict incoming tickets to basic Tier 1 tasks until they prove they can follow the SOP.

SOP-007 | Cybersecurity and Networking

Suspicious Network Connections and Open Ports Check

Symptoms: Workstation shows unusually slow bandwidth, unexpected outbound traffic, and/or security alerts flagging unfamiliar background connections.

Troubleshooting & Containment Steps:

  • Open Command Prompt as Administrator and run netstat -ano to lost all active TCP/UDP connections, listening ports, and ther Process IDs (PIDs).
  • Review the Foreign Address and State ( ESTABLISHED or LISTENING) columns to spot unfamiliar external IP addresses or unusual ports.
  • Find the exact program behind a suspicious PID by running tasklist | findstr [PID] in Command Prompt or checking the Details tab in Task Manager (Ctrl + Shift + Esc)
  • Run a quick Windows Defender scan and check the Windows Defender Firewall rules to verify no unauthorized apps were allowed through.

Escalation Criteria: Escalate immediately to Tier-2 Security Operations if an unrecognized process maintains an active connection to an external IP on non-standard ports, or if a known sytem process behaves abnormally.
